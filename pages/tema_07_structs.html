De datos aislados a entidades completas

Los tipos básicos como int, float y char son suficientes para representar valores individuales. Sin embargo, una entidad como un alumno necesita matrícula, nombre, edad, sexo y estado. Un struct permite reunir todos esos campos bajo un mismo tipo.

7.1 · ¿Qué es un struct?

📦

Agrupa

Reúne variables de diferentes tipos bajo un mismo nombre. Cada variable interna se conoce como campo o miembro.

🧑‍🎓

Modela

Permite representar alumnos, empleados, productos, fechas, coordenadas, registros y otras entidades reales.

🧠

Organiza

Mantiene información relacionada dentro de una sola variable lógica, simplificando el diseño del programa.

💾

Registra

Es muy útil para construir registros que posteriormente pueden almacenarse en archivos de texto o binarios.

Declaración básica de una estructura
struct_alumno.c
struct Alumno
{
    int matricula;
    char nombre[30];
    int edad;
};

int main(void)
{
    struct Alumno alumno1;

    alumno1.matricula = 2024001;
    alumno1.edad = 20;

    return 0;
}
💡
RECUERDA
El operador punto . se utiliza para acceder a los campos de una variable de tipo estructura: alumno1.edad.

7.2 · typedef con estructuras

El documento base utiliza el estilo typedef struct para crear un nombre de tipo más corto. De esta forma, en lugar de declarar struct _talum alumno1;, podemos escribir simplemente Ts_alum alumno1;.

typedef_struct.c
typedef struct _alumno
{
    int matricula;
    char nombre[30];
    int edad;
} Ts_alum;

int main(void)
{
    Ts_alum alumno1;

    alumno1.matricula = 2024001;
    alumno1.edad = 20;

    return 0;
}
Ventaja didáctica: typedef hace que el nombre del tipo sea más legible y facilita reutilizarlo en funciones, arreglos y archivos.

7.3 · Estructuras anidadas

Una estructura puede contener otra estructura como uno de sus campos. Esto permite dividir una entidad compleja en partes lógicas más pequeñas.

alumno_anidado.c
#include <stdio.h>
#include <string.h>

typedef struct _nom
{
    char nombre[30];
    char appat[30];
    char apmat[30];
} Ts_nom;

typedef struct _talum
{
    int status;
    int matri;
    Ts_nom nombre;
    int edad;
    int sexo;
} Ts_alum;

int main(void)
{
    Ts_alum alumno1;

    alumno1.matri = 2024001;
    alumno1.edad = 20;
    alumno1.status = 1;

    strcpy(alumno1.nombre.nombre, "ANA");
    strcpy(alumno1.nombre.appat, "GARCIA");
    strcpy(alumno1.nombre.apmat, "LOPEZ");

    printf("%s %s %s\n",
           alumno1.nombre.nombre,
           alumno1.nombre.appat,
           alumno1.nombre.apmat);

    return 0;
}
🏠
Analogía: un Ts_alum es como una casa y Ts_nom es una habitación dentro de ella. Para llegar al dato nombre usamos la ruta completa: alumno1.nombre.nombre.

7.4 · Enviar estructuras a funciones

Una estructura permite enviar varios datos relacionados a una función utilizando un solo parámetro. Esto reduce listas largas de argumentos y mejora la claridad.

Por valor
void mostrar_alumno(Ts_alum a)
{
    printf("%d\n", a.matri);
    printf("%s\n", a.nombre.nombre);
    printf("%d\n", a.edad);
}
Por referencia
void cambiar_edad(Ts_alum *a, int nueva)
{
    a->edad = nueva;
}

/* llamada */
cambiar_edad(&alumno1, 21);
🔎
PUNTO VS. FLECHA
Variable normal de estructura: alumno.edad.
Puntero a estructura: alumno->edad.

7.5 · Arreglos de estructuras

Después de estudiar arreglos en el Tema 6, podemos combinar ambos conceptos: un arreglo puede almacenar muchas estructuras del mismo tipo. Así obtenemos una colección de registros.

grupo_alumnos.c
#define MAX 30

Ts_alum grupo[MAX];

for (int i = 0; i < MAX; i++)
{
    grupo[i].matri = 0;
    grupo[i].edad = 0;
    grupo[i].status = 0;
}

/* acceso a un registro */
grupo[3].matri = 2024015;
Un arreglo de estructuras es una excelente introducción al concepto de registros. Cada posición representa una entidad completa.

7.6 · Punteros a estructuras

Un puntero puede almacenar la dirección de una estructura. Esta técnica será especialmente importante más adelante para trabajar con memoria dinámica y estructuras enlazadas.

puntero_struct.c
Ts_alum alumno1;
Ts_alum *ptr;

ptr = &alumno1;

ptr->matri = 2024008;
ptr->edad = 19;

printf("%d\n", ptr->matri);
📍
Idea: el puntero no contiene al alumno; contiene la dirección donde está almacenado. El operador -> sigue esa dirección y accede al campo solicitado.

7.7 · union: varios nombres, la misma memoria

Una union se parece a un struct, pero todos sus miembros comparten el mismo espacio de memoria. Por eso normalmente solo un miembro contiene un valor válido a la vez.

union_dato.c
typedef union _dato
{
    int entero;
    float decimal;
    char caracter;
} Ts_dato;

Ts_dato dato;

dato.entero = 65;
printf("%d\n", dato.entero);

dato.decimal = 3.14f;
printf("%.2f\n", dato.decimal);
Cuidado: al guardar un valor en otro miembro de la unión, se reutilizan los mismos bytes. No debes asumir que los valores anteriores permanecen válidos.

7.8 · enum: constantes con nombre

Un enum permite crear nombres simbólicos para valores enteros. En lugar de usar números difíciles de recordar, podemos escribir ACTIVO, INACTIVO, MUJER o HOMBRE.

enum_alumno.c
typedef enum
{
    INACTIVO = 0,
    ACTIVO = 1
} Te_status;

typedef enum
{
    MUJER = 1,
    HOMBRE = 2
} Te_sexo;

typedef struct _alumno
{
    int matricula;
    int edad;
    Te_status status;
    Te_sexo sexo;
} Ts_alum;

Ts_alum alumno1;

alumno1.status = ACTIVO;
alumno1.sexo = MUJER;
✨
MEJOR LEGIBILIDAD
alumno.status = ACTIVO; comunica mejor la intención del programa que alumno.status = 1;.

Struct vs Union vs Enum

Característica Struct Union Enum
Propósito Agrupar datos relacionados. Compartir memoria entre diferentes representaciones. Crear constantes enteras con nombre.
Memoria Considera todos los miembros, además de posible padding. Debe ser suficiente para su miembro más grande. Representación integral definida por la implementación.
Uso simultáneo Sí, todos los campos pueden contener valores. Normalmente un miembro válido a la vez. No aplica: representa valores simbólicos.
Ejemplo Alumno, producto, fecha. Dato entero o decimal alternativo. Estados, opciones, categorías.
Precisión importante: el tamaño exacto de un struct, union o enum puede depender de la plataforma, compilador, alineación y representación utilizada. Usa sizeof cuando necesites conocerlo en tu programa.

Buenas prácticas

1. Usa nombres que expliquen qué representa cada estructura.
2. Agrupa únicamente campos que pertenezcan a la misma entidad.
3. Inicializa los campos antes de utilizarlos.
4. Para cadenas, copia el texto con funciones apropiadas; no uses = entre arreglos.
5. Utiliza enum cuando un campo tenga un conjunto pequeño de estados conocidos.
6. Usa punteros cuando una función deba modificar la estructura original o cuando quieras evitar copias grandes.
