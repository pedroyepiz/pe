La condición divide el problema en caminos posibles. El programa solo sigue el camino correspondiente.

💡 La selección evita que todos los programas ejecuten siempre exactamente las mismas instrucciones.
3.1.1 · SENTENCIA if · FORMA SIMPLE

La forma simple ejecuta un bloque solo si la condición es verdadera. Si es falsa, el bloque se omite y el programa continúa.

if_simple.c
#include <stdio.h>

int main() {
    int edad;
    printf("Ingresa tu edad: ");
    scanf("%d", &edad);

    if (edad >= 18) {
        printf("Eres mayor de edad.\n");
    }

    printf("Fin del programa.\n");
    return 0;
}
✅ Buena práctica: usa siempre llaves { }, incluso cuando el bloque tenga una sola instrucción.
3.1.2 · SELECCIÓN COMPUESTA · if-else

Se utiliza cuando el problema tiene dos alternativas mutuamente excluyentes. Esta es la forma compuesta de la selección.

if_else.c
if (temperatura > 37.5) {
    printf("Tienes fiebre.\n");
}
else {
    printf("Tu temperatura es normal.\n");
}

3.1.3 · PROPIEDAD DE ANIDACIÓN
Idea clave: la anidación es una propiedad que sirve para direccionar el flujo de los procesos. Consiste en colocar una estructura de selección dentro de otra para decidir con mayor precisión qué camino seguirá el programa.
Muy importante: en esencia, en selección solo existen dos tipos base: simple y compuesta. La anidación no es un tercer tipo independiente; es el resultado de juntar condiciones simples y compuestas.

Anidada por verdadero

La segunda condición se evalúa solo cuando la primera fue verdadera.

Anidada por falso

La segunda decisión se coloca dentro de la rama else.

Anidada falso / verdadero

Puede haber decisiones internas en ambas ramas.

En cascada

Serie de decisiones enlazadas para clasificar varios casos.

✅ Anidada por verdadero

anidada_verdadero.c
if (usuarioValido) {
    if (passwordCorrecto) {
        printf("Entrar al sistema\n");
    }
    else {
        printf("Solicitar reintento\n");
    }
}
else {
    printf("Acceso denegado\n");
}

✅ Anidada por falso

anidada_falso.c
if (tieneBeca) {
    printf("Aplicar descuento directo\n");
}
else {
    if (promedio >= 90) {
        printf("Aplicar apoyo por mérito\n");
    }
    else {
        printf("Sin descuento\n");
    }
}

✅ Anidada por falso / verdadero

anidada_mixta.c
if (esAdmin) {
    if (activo) {
        printf("Panel de administración\n");
    }
    else {
        printf("Cuenta desactivada\n");
    }
}
else {
    if (visitante) {
        printf("Página pública\n");
    }
    else {
        printf("Acceso restringido\n");
    }
}

✅ Anidación en cascada

cascada_notas.c
if (nota >= 90) {
    printf("A\n");
}
else {
    if (nota >= 80) {
        printf("B\n");
    }
    else {
        if (nota >= 70) {
            printf("C\n");
        }
        else {
            printf("F\n");
        }
    }
}
⚠️ Buena práctica: la anidación es poderosa, pero cuando se vuelve demasiado profunda puede dificultar la lectura. Conviene modularizar, usar sangría clara y evitar anidaciones innecesarias.
3.2.1 · “SELECCIÓN MÚLTIPLE” CON CADENA if-else if-else
Corrección importante: en C no existe una estructura especial llamada else if. Lo que realmente existe es else seguido de otro if. Es una forma práctica de escribir anidación para simular una selección múltiple.
La escritura else if (condición) equivale conceptualmente a else { if (condición) { ... } }.

Se usa mucho por comodidad y legibilidad, pero no debe confundirse con una estructura nueva del lenguaje. Cuando la cadena crece demasiado, en buenas prácticas suele recomendarse evitar abusar de ella.

cadena_if.c
if (calificacion == 'A') {
    printf("Excelente trabajo.\n");
}
else if (calificacion == 'B') {
    printf("Muy bien.\n");
}
else if (calificacion == 'C') {
    printf("Suficiente.\n");
}
else {
    printf("Calificación inválida.\n");
}
✅ Si son pocos casos puede ser aceptable. Si hay muchos valores discretos, generalmente switch será más claro.

Ventaja

Permite evaluar rangos y expresiones lógicas.

Riesgo

Abusar de la cadena puede volver el código largo y difícil de mantener.

Recomendación

Para muchos valores constantes, suele convenir switch.

3.2.2 · SENTENCIA switch

switch es apropiado cuando una expresión se compara contra varios valores constantes. En muchos escenarios reemplaza mejor a largas cadenas de else if.

switch_base.c
switch (expresion_entera) {
    case valor1:
        // instrucciones
        break;

    case valor2:
        // instrucciones
        break;

    default:
        // opción no contemplada
}

3.2.2.2 · USO DE break Y FALL-THROUGH

⚠️ Sin break

fallthrough.c
int dia = 2;

switch (dia) {
    case 1:
        printf("Lunes\n");
        break;

    case 2:
        printf("Martes\n");

    case 3:
        printf("Miércoles\n");
        break;
}
Salida: Martes y después Miércoles.

✅ Fall-through intencional

mismo_caso.c
switch (opcion) {
    case 'a':
    case 'A':
        printf("Opción A seleccionada.\n");
        break;
}
✅ Dos valores distintos pueden compartir el mismo bloque.
3.2.2.3 · CASO default
menu_switch.c
int opcion;
printf("Menú: 1=Sumar, 2=Restar, 3=Salir\n");
scanf("%d", &opcion);

switch (opcion) {
    case 1:
        // sumar
        break;
    case 2:
        // restar
        break;
    case 3:
        printf("Saliendo...\n");
        break;
    default:
        printf("Opción no válida.\n");
}
🛡️ Incluir default crea una salida segura para valores inesperados.

EN RESUMEN
En selección, la base real en C es simple y compuesta. La anidación surge de combinar esas decisiones para direccionar el flujo. La escritura else if no es una estructura especial del lenguaje: es una forma práctica de expresar anidación. Para muchos valores constantes, switch suele ser una alternativa más clara.
