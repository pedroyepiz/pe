Métodos de Ordenación y Búsqueda

Técnicas para organizar información y localizar datos de forma eficiente. Incluye clasificación, eficiencia, código en C y animaciones didácticas para visualizar paso a paso cómo trabaja cada algoritmo.

IDEA CENTRAL

Ordenar primero, buscar después

En programación, una colección de datos puede representarse mediante arreglos, vectores o registros. Cuando esa información crece, se vuelve necesario organizarla para trabajar mejor con ella. Ahí aparecen los algoritmos de ordenación, que reorganizan los elementos; y los algoritmos de búsqueda, que permiten localizar un dato específico.

La ventaja de estudiar estos métodos no es únicamente aprender a programarlos, sino entender cómo piensan los algoritmos: comparan, intercambian, insertan, dividen el problema y aprovechan estructuras ya ordenadas para reducir trabajo.

13.1 · ¿Qué son los métodos de ordenación?

Un método de ordenación es un algoritmo que reorganiza una colección de datos siguiendo un criterio definido. En C, normalmente se trabaja con arreglos de enteros, flotantes, caracteres o incluso arreglos de struct.

El objetivo de ordenar es facilitar procesos posteriores como:

  • Presentar resultados de forma clara y ordenada.
  • Preparar datos para búsquedas más eficientes.
  • Comparar valores mínimos, máximos o rangos.
  • Trabajar con reportes, estadísticas o listados.
  • Mejorar la organización lógica de la información.

13.2 · ¿Cómo se catalogan los métodos de ordenación?

No todos los algoritmos ordenan de la misma forma. Su clasificación ayuda a entender la estrategia que usan.

Internos

Trabajan con datos que caben completamente en memoria principal.

Ejemplos: burbuja, selección, inserción, quicksort.

Externos

Se aplican cuando la cantidad de datos es tan grande que requiere almacenamiento secundario.

Ejemplo clásico: mezcla externa.

Por intercambio

Comparan elementos e intercambian posiciones si están desordenados.

Ejemplos: burbuja, quicksort.

Por inserción

Van construyendo una zona ordenada e insertan ahí el siguiente elemento.

Ejemplos: inserción y shell sort.

Por selección

Eligen repetidamente el menor o mayor valor restante.

Ejemplo: selección directa.

Divide y vencerás

Dividen el problema en partes más pequeñas, las resuelven y luego combinan resultados.

Ejemplos: merge sort y quick sort.

13.3 · Eficiencia de los métodos de ordenación

La eficiencia de un algoritmo se mide por tiempo, memoria, escalabilidad y estabilidad.

Tiempo

Cuántas operaciones realiza al ordenar n elementos.

Memoria

Cuánta memoria adicional necesita además del arreglo original.

Escalabilidad

Qué tan bien se comporta cuando la cantidad de datos crece mucho.

Estabilidad

Si conserva o no el orden relativo de elementos iguales.

La notación Big O expresa cómo crece el costo del algoritmo cuando aumenta la cantidad de elementos n.

O(1)Constante
O(log n)Logarítmica
O(n)Lineal
O(n log n)Muy eficiente para ordenar
O(n²)Costosa en listas grandes
Un algoritmo sencillo puede ser suficiente cuando el arreglo es pequeño. Pero cuando el tamaño crece, la diferencia entre un método O(n²) y uno O(n log n) se vuelve muy importante.

13.5 · Explicación ampliada de los métodos de ordenación

Burbuja

¿En qué consiste? Recorre el arreglo comparando pares consecutivos. Si están en orden incorrecto, los intercambia.

Idea clave: en cada pasada “sube” el valor más grande hacia el final.

Ventaja: muy fácil de comprender e implementar.

Desventaja: realiza demasiadas comparaciones cuando el arreglo es grande.

Cuándo usarlo: fines didácticos o listas muy pequeñas.

Selección

¿En qué consiste? Busca el menor elemento del tramo no ordenado y lo coloca en su posición correcta.

Idea clave: en cada pasada fija definitivamente un elemento.

Ventaja: hace pocos intercambios.

Desventaja: sigue necesitando muchas comparaciones.

Cuándo usarlo: cuando se desea una implementación clara y simple.

Inserción

¿En qué consiste? Toma cada elemento y lo inserta en la posición correcta dentro de la parte ya ordenada.

Idea clave: funciona como ordenar cartas en la mano.

Ventaja: es muy bueno cuando los datos ya están casi ordenados.

Desventaja: en el peor caso sigue siendo O(n²).

Cuándo usarlo: arreglos pequeños o casi ordenados.

Shell Sort

¿En qué consiste? Compara elementos separados por “saltos” y reduce gradualmente esa separación.

Idea clave: mueve más rápido elementos lejanos a su zona correcta.

Ventaja: mejora notablemente a inserción directa.

Desventaja: su eficiencia depende mucho de la secuencia de saltos.

Cuándo usarlo: cuando se necesita una mejora intermedia sin mucha complejidad.

Merge Sort

¿En qué consiste? Divide el arreglo en mitades, ordena cada mitad y luego las fusiona.

Idea clave: aplica “divide y vencerás”.

Ventaja: garantiza O(n log n) y es estable.

Desventaja: requiere memoria extra.

Cuándo usarlo: cuando importa la estabilidad o se procesan muchos datos.

Quick Sort

¿En qué consiste? Elige un pivote, separa los menores a un lado y los mayores al otro, y repite el proceso.

Idea clave: divide el problema alrededor del pivote.

Ventaja: suele ser uno de los más rápidos en la práctica.

Desventaja: un mal pivote puede llevarlo a O(n²).

Cuándo usarlo: ordenación general muy eficiente en la práctica.

Heap Sort

¿En qué consiste? Usa un heap para colocar repetidamente el mayor elemento al final.

Idea clave: aprovecha una estructura jerárquica.

Ventaja: siempre se mantiene en O(n log n).

Desventaja: es menos intuitivo que otros métodos.

Cuándo usarlo: cuando se busca rendimiento predecible.

burbuja_seleccion.c
// Método tipo burbuja / selección simple
void burbuja_seleccion(int vect[], int m)
{
    int i, j;
    int temp;

    for (i = 0; i < m - 1; i++)
    {
        for (j = i + 1; j < m; j++)
        {
            if (vect[j] < vect[i])
            {
                temp = vect[j];
                vect[j] = vect[i];
                vect[i] = temp;
            }
        }
    }
}
🧠
El código anterior es muy útil para clase porque muestra la lógica de comparar e intercambiar. Ayuda a entender la idea de ordenación aunque existan algoritmos más eficientes.

13.7 · Métodos de búsqueda

Un método de búsqueda intenta localizar un valor dentro de una colección.

🔎

Búsqueda secuencial

Revisa los elementos uno por uno desde el inicio hasta encontrar el valor.

⚡

Búsqueda binaria

Divide repetidamente la zona de búsqueda a la mitad. Requiere datos ordenados.

13.8 · Búsqueda secuencial

También llamada búsqueda lineal. Recorre la colección desde la primera posición hasta encontrar el elemento o llegar al final.

Inicio Comparar dato actual ¿Es el buscado? Sí: regresar posición
No: continuar
busqueda_secuencial.c
int busqueda_secuencial(int datos[], int n, int valor)
{
    for (int i = 0; i < n; i++)
    {
        if (datos[i] == valor)
        {
            return i;
        }
    }

    return -1;
}
📌
Complejidad: O(n). No requiere que los datos estén ordenados.

13.9 · Búsqueda binaria

La búsqueda binaria compara el valor buscado con el elemento central y reduce la zona de búsqueda.

Condición indispensable: el arreglo debe estar previamente ordenado.
busqueda_binaria.c
int busqueda_binaria(int datos[], int n, int valor)
{
    int izquierda = 0;
    int derecha = n - 1;

    while (izquierda <= derecha)
    {
        int medio = izquierda + (derecha - izquierda) / 2;

        if (datos[medio] == valor)
        {
            return medio;
        }

        if (datos[medio] < valor)
        {
            izquierda = medio + 1;
        }
        else
        {
            derecha = medio - 1;
        }
    }

    return -1;
}
⚡
Complejidad: O(log n). Es mucho más eficiente que la búsqueda secuencial cuando los datos son grandes y ya están ordenados.
