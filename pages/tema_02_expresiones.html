2.1.1 · OPERADORES ARITMÉTICOS

Trabajan con valores numéricos. En C los operadores básicos son:

+

Suma

a + b

−

Resta

a - b

*

Multiplicación

a * b

/

División

a / b

%

Módulo

Obtiene el residuo de una división entre enteros. Muy útil para paridad, ciclos e índices circulares.

🔍

Ejemplo

Si a=10 y b=3: suma=13, resta=7, multiplicación=30, división entera=3 y módulo=1.

aritmetica.c
#include <stdio.h>

int main(void) {
    int a = 10, b = 3;
    double x = 10.0, y = 3.0;

    printf("%d\n", a / b);             // 3: división entera
    printf("%.2f\n", x / y);          // 3.33
    printf("%.2f\n", (double)a / b); // 3.33
    printf("Residuo: %d\n", a % b); // 1
    return 0;
}
💡 División entera: si ambos operandos son enteros, se descarta la parte fraccionaria. Si al menos uno es flotante, el resultado puede conservar decimales.

int prom = 60;

logica.c
#include <stdio.h>
#include <stdbool.h>

int edad = 20;
bool tiene_licencia = true;

if (edad >= 18 && tiene_licencia) {
    printf("Puede conducir.\n");
}

if (edad < 16 || !tiene_licencia) {
    printf("No puede conducir.\n");
}
✅ Regla mnemotécnica: && = “y además”, || = “o también”, ! = “no”.

2.2.3 · EVALUACIÓN DE CORTOCIRCUITO

C evita evaluar una condición cuando el resultado ya puede determinarse.

⚡ AND &&

Si la primera condición es falsa, la segunda ya no se evalúa.

A = falso→DETENER→Resultado = falso

⚡ OR ||

Si la primera condición es verdadera, la segunda ya no se evalúa.

A = verdadero→DETENER→Resultado = verdadero
cortocircuito.c
int x = 0;

if (x != 0 && 10 / x > 2) {
    printf("Condición verdadera\n");
}
// Si x == 0, 10/x no se evalúa: se evita división por cero.
2.3 · CONVERSIÓN DE TIPOS
📈

Conversión implícita

C promueve automáticamente tipos pequeños y combina operandos según las reglas de conversión usuales.

🎭

Casting explícito

El programador indica el tipo deseado mediante (tipo) expresión.

casting.c
char c = 'A';      // 65
int i = 10;
double d = 3.14;
double r = c + i + d; // 78.14

int a = 5, b = 2;
double promedio = (double)a / b; // 2.5

double pi = 3.14159;
int entero_pi = (int)pi; // 3
🔎 Aclaración técnica: al mezclar int y float, la operación se realiza con conversión al tipo apropiado; si el resultado final se asigna a un int, allí se descarta la parte decimal.
