Manejo de Archivos en C

Persistencia de datos, archivos de texto y binarios, acceso aleatorio e indexación mediante un vector de índices.

“La memoria guarda mientras el programa vive; el archivo conserva cuando el programa termina.”
IDEA CENTRAL

De datos temporales a información persistente

Las variables y arreglos existen principalmente mientras el programa se está ejecutando. Un archivo permite conservar información en almacenamiento externo para recuperarla, modificarla o procesarla posteriormente.

En C, el manejo de archivos se realiza principalmente mediante la biblioteca <stdio.h>, un puntero de tipo FILE * y funciones especializadas de apertura, lectura, escritura, posicionamiento y cierre.

12.1 · Definiciones fundamentales

📄

Archivo

Conjunto de datos almacenados de forma permanente en un medio externo.

🧾

Registro

Unidad lógica de información. En C suele representarse mediante un struct.

📍

Cursor

Posición actual desde la que se leerá o escribirá dentro del archivo.

🔌

Flujo

Camino lógico por el que los datos entran al programa o salen hacia un archivo.

💡
IDEA CLAVE
La RAM es volátil. Los archivos permiten conservar información cuando el programa termina y volver a utilizarla en ejecuciones posteriores.

12.2 · Generalidades y clasificación de archivos

El material de referencia clasifica los archivos desde cuatro puntos de vista: dirección del flujo, representación de los datos, tipo de acceso y longitud de los registros.

Dirección del flujo

Entrada: archivo → programa.

Salida: programa → archivo.

Entrada/Salida: ambas operaciones.

Representación

Texto: la información se representa como caracteres.

Binario: se almacenan bytes con la representación interna de los datos.

Tipo de acceso

Secuencial: se procesa en orden.

Aleatorio: permite saltar a una posición concreta.

Longitud de registro

Variable: los registros pueden tener tamaños diferentes.

Constante: todos ocupan el mismo número de bytes.

12.3 · Apertura, escritura y cierre

En C se utiliza FILE * para trabajar con un archivo. La función fopen() intenta abrirlo y devuelve NULL si no puede hacerlo.

apertura_basica.c
#include <stdio.h>

int main(void)
{
    FILE *archivo;

    archivo = fopen("datos.txt", "r");

    if (archivo == NULL)
    {
        printf("No se pudo abrir el archivo.\n");
        return 1;
    }

    fclose(archivo);
    return 0;
}

"r+"Lectura / escrituraConserva contenidoFalla

Para archivos binarios se agrega b: "rb", "wb", "r+b", "w+b". En Windows esta diferencia es especialmente importante.

12.5 · Archivos de texto

Un archivo de texto almacena información como caracteres. Es apropiado cuando interesa que el contenido pueda ser leído o editado fácilmente con un editor de texto.

✍️

Escritura

fprintf(), fputs() y fputc().

📖

Lectura

fscanf(), fgets() y fgetc().

archivo_texto.c
#include <stdio.h>

int main(void)
{
    FILE *f;
    char nombre[40];
    int edad;

    f = fopen("alumnos.txt", "w");

    if (f == NULL)
    {
        printf("Error al crear el archivo.\n");
        return 1;
    }

    fprintf(f, "ANA 20\n");
    fprintf(f, "LUIS 21\n");

    fclose(f);

    f = fopen("alumnos.txt", "r");

    if (f == NULL)
        return 1;

    while (fscanf(f, "%39s %d", nombre, &edad) == 2)
    {
        printf("%s - %d\n", nombre, edad);
    }

    fclose(f);
    return 0;
}
📌
VENTAJA: fácil de consultar.
LIMITACIÓN: convertir texto a números o estructuras requiere interpretación y formato consistente.

12.6 · Archivos binarios

Los archivos binarios permiten guardar registros completos con fwrite() y recuperarlos con fread(). Son especialmente útiles cuando todos los registros tienen longitud constante.

registros_binarios.c
#include <stdio.h>

typedef struct
{
    int matricula;
    char nombre[30];
    float promedio;
} stAlumno;

int main(void)
{
    FILE *f;
    stAlumno alumno = {36276, "ANA LOPEZ", 9.4f};

    f = fopen("alumnos.dat", "wb");

    if (f == NULL)
        return 1;

    fwrite(&alumno, sizeof(stAlumno), 1, f);

    fclose(f);
    return 0;
}
⚡

Rápidos

Evitan convertir cada campo a texto.

📦

Registros

Se adaptan naturalmente a datos definidos con struct.

📏

Tamaño fijo

Facilita calcular la posición de cualquier registro.

🔒

No legibles

No se interpretan correctamente con un editor de texto común.

12.8 · Archivos indexados usando un vector de índices

Para esta unidad utilizaremos un enfoque didáctico: el archivo binario principal conserva los registros completos y en memoria mantenemos un vector de índices. Cada elemento del vector guarda una clave y la posición del registro dentro del archivo.

VECTOR DE ÍNDICES EN RAM [clave → posición] [36270 → 4] [36276 → 0] [36310 → 2]
ARCHIVO PRINCIPAL alumnos.dat Registro 0 Registro 1 Registro 2...
indice.h
typedef struct
{
    int clave;       // matrícula u otra llave
    long posicion;   // número de registro en alumnos.dat
} stIndice;

stIndice indice[1000];
int n_indices = 0;

Construir el vector de índices

construir_indice.c
void construir_indice(FILE *f,
                      stIndice indice[],
                      int *n)
{
    stAlumno alumno;
    long pos = 0;

    *n = 0;
    rewind(f);

    while (fread(&alumno, sizeof(stAlumno), 1, f) == 1)
    {
        indice[*n].clave = alumno.matricula;
        indice[*n].posicion = pos;

        (*n)++;
        pos++;
    }
}
Después de construir el vector se puede ordenar por clave sin mover físicamente los registros del archivo principal. Sobre el vector ordenado puede aplicarse una búsqueda binaria.

Buscar en el índice y recuperar el registro

buscar_indexado.c
int buscar_indice(stIndice indice[], int n, int clave)
{
    int ini = 0;
    int fin = n - 1;

    while (ini <= fin)
    {
        int medio = ini + (fin - ini) / 2;

        if (indice[medio].clave == clave)
            return medio;

        if (indice[medio].clave < clave)
            ini = medio + 1;
        else
            fin = medio - 1;
    }

    return -1;
}

/* Después de encontrarlo: */

int p = buscar_indice(indice, n_indices, 36276);

if (p != -1)
{
    long registro = indice[p].posicion;

    fseek(archivo,
          registro * sizeof(stAlumno),
          SEEK_SET);

    fread(&alumno, sizeof(stAlumno), 1, archivo);
}
🎯
PRINCIPIO DEL ARCHIVO INDEXADO
No ordenamos continuamente todo el archivo de datos. Ordenamos un vector pequeño que contiene clave + posición. La búsqueda se realiza sobre ese vector y después usamos la posición encontrada para ir directamente al registro.

12.9 · Eliminación, borrado lógico y mantenimiento

El material de referencia señala que no existe una función que elimine directamente bytes intermedios y desplace automáticamente todo lo que sigue. Por eso se utilizan estrategias de mantenimiento.

🚫

Borrado lógico

Agregar un campo de estado, por ejemplo valido, y marcar el registro sin quitarlo físicamente.

🧹

Empaquetado

Crear un archivo temporal y copiar únicamente los registros válidos.

borrado_logico.c
typedef struct
{
    char valido;     // 'S' = activo, 'N' = eliminado
    int matricula;
    char nombre[30];
} stAlumno;

/* marcar como eliminado */
alumno.valido = 'N';
Si cambia el archivo principal, el vector de índices también debe actualizarse o reconstruirse. Un índice desactualizado puede apuntar al registro equivocado.

12.10 · Programa integrador · archivo binario con registros

El siguiente ejemplo sintetiza el flujo principal: abrir o crear un archivo binario, insertar registros al final, consultar por número de registro y cerrar correctamente.

archivo_registros.c
#include <stdio.h>

typedef struct
{
    char valido;
    int matricula;
    char nombre[30];
    float promedio;
} stAlumno;

int main(void)
{
    FILE *f;
    stAlumno alumno;
    long numero;

    f = fopen("alumnos.dat", "r+b");

    if (f == NULL)
        f = fopen("alumnos.dat", "w+b");

    if (f == NULL)
    {
        printf("No se pudo abrir el archivo.\n");
        return 1;
    }

    /* INSERTAR AL FINAL */
    alumno.valido = 'S';
    alumno.matricula = 36276;
    snprintf(alumno.nombre, sizeof(alumno.nombre), "ANA LOPEZ");
    alumno.promedio = 9.4f;

    fseek(f, 0, SEEK_END);
    fwrite(&alumno, sizeof(stAlumno), 1, f);

    /* CONSULTAR REGISTRO 0 */
    numero = 0;

    fseek(f,
          numero * sizeof(stAlumno),
          SEEK_SET);

    if (fread(&alumno, sizeof(stAlumno), 1, f) == 1)
    {
        if (alumno.valido == 'S')
        {
            printf("%d %s %.2f\n",
                   alumno.matricula,
                   alumno.nombre,
                   alumno.promedio);
        }
    }

    fclose(f);
    return 0;
}
