Cadenas y biblioteca propia

Ejemplo básico de manejo de cadenas en C/C++ y de cómo separar funciones en una biblioteca propia para reutilizarlas desde el programa principal.

“Una biblioteca propia separa lo reutilizable del programa principal.”

🧩 Propósito del ejemplo

Este material muestra dos ideas del Tema 6: primero, cómo declarar, leer, recorrer e imprimir una cadena; segundo, cómo colocar una función reutilizable en un archivo de biblioteca propio y mandarla llamar desde el programa principal.

💡
ESTRUCTURA DEL EJEMPLO
El programa principal incluye "karely_ruiz.h". En ese archivo se encuentra la función my_fgets(), utilizada para leer una cadena. Después el programa usa strlen() para conocer su longitud y recorre la cadena carácter por carácter.

Archivo 2 · Biblioteca propia (.h)
karely_ruiz.h

void my_fgets(char cadena[],int tam)
{
	int i = 0;
	fflush(stdin);
	fgets(cadena,tam,stdin);

	while (cadena[i] != '\0')
	{
		i++;
	}
	cadena[i-1] = '\0';
}

🔗 ¿Cómo se relacionan los dos archivos?

La instrucción #include "karely_ruiz.h" incorpora al programa principal las declaraciones y funciones contenidas en la biblioteca propia. De esta forma, programa.cpp puede utilizar my_fgets() sin volver a escribir su desarrollo.

📌
IDEA CLAVE PARA EL ALUMNO
El archivo .cpp contiene la lógica principal del programa y el archivo .h concentra código que puede reutilizarse. Esta separación ayuda a construir programas más ordenados, modulares y fáciles de mantener.

🧠 Qué observar en el manejo de cadenas

En el ejemplo se declara una cadena con char cadena[30], se obtiene su longitud mediante strlen(), se captura otra cadena usando my_fgets() y finalmente se recorre carácter por carácter en sentido ascendente y descendente.
