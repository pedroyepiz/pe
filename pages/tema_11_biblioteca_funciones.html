IDEA CENTRAL

¿Por qué usar bibliotecas?

Una librería o biblioteca reúne código que puede ser reutilizado: funciones, prototipos, constantes, macros y tipos definidos por el usuario. En Programación Estructurada su propósito principal es evitar repetir soluciones que ya fueron programadas y probadas.

11.1 · ¿Qué son las librerías o bibliotecas en C?

Una biblioteca contiene código preescrito que puede ser incorporado a otros programas. Puede incluir funciones, definiciones de tipos (typedef), macros (#define) y constantes.

🏛️

Librerías estándar

Vienen con el compilador o forman parte de la biblioteca estándar de C. Ejemplos: stdio.h, stdlib.h, string.h y math.h.

🛠️

Librerías propias

Son creadas por el programador para resolver necesidades específicas de un proyecto, práctica o curso.

♻️

Reutilización

Una función bien diseñada puede utilizarse en muchos programas sin volver a escribir su lógica.

🧩

Abstracción

El programa principal puede utilizar una función sin conocer cada detalle de su implementación.

💡
IDEA DEL MANUAL
En lugar de repetir funciones complejas —por ejemplo validaciones de entrada o lectura de cadenas— se programan una vez, se guardan y se reutilizan.

11.2 · ¿Qué significa #include?

#include es una directiva del preprocesador. No es una instrucción ejecutable del programa: se procesa antes de la compilación.

#

El símbolo #

Indica que la línea corresponde al preprocesador. Es una orden que se atiende antes de compilar el código C.

📎

La palabra include

Le indica al preprocesador que incorpore el contenido del archivo especificado en ese punto del código fuente.

📄
Analogía: imagina un documento al que le insertas el contenido de otro archivo antes de imprimirlo. El preprocesador hace algo equivalente antes de que el compilador procese el programa.

11.4 · Librerías comunes del sistema

Antes de crear una función propia conviene revisar si la biblioteca estándar ya ofrece una solución.

<stdio.h>
Entrada y salida estándar
printf()scanf()fgets()puts()FILE
<stdlib.h>
Utilidades generales
atoi()rand()malloc()free()exit()
<string.h>
Manejo de cadenas
strlen()strcpy()strcat()strcmp()strcspn()
<math.h>
Funciones matemáticas
sqrt()pow()sin()cos()fabs()
<time.h>
Fecha, hora y tiempo
time()clock()difftime()
<ctype.h>
Clasificación de caracteres
isdigit()isalpha()toupper()tolower()
<conio.h>
Consola en algunos compiladores
getch()kbhit()

No pertenece al estándar ISO C; su disponibilidad depende del compilador.

Importante: stdio.h, stdlib.h, string.h, math.h, time.h y ctype.h forman parte del ecosistema estándar de C. conio.h es común en ciertos entornos, pero no es portable.

11.6 · Estructura interna de una biblioteca propia

Archivo de biblioteca · kareli_ruiz.h
kareli_ruiz.h
/* propietario: PEDRO NUÑEZ YEPIZ
   versión: 1.1 */

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define N 15
#define N2 20
#define SALTO printf("\n");

/* PROTOTIPOS */
void my_fgets(char cadena[], int tam);
int my_int(int ri, int rf, const char msge[]);

/* DESARROLLO */
void my_fgets(char cadena[], int tam)
{
    int i = 0;
    fgets(cadena, tam, stdin);

    while (cadena[i] != '\0')
    {
        i++;
    }

    if (i > 0 && cadena[i-1] == '\n')
    {
        cadena[i-1] = '\0';
    }
}

int my_int(int ri, int rf, const char msge[])
{
    int num;
    char my_num[30];

    do
    {
        printf("%s", msge);
        my_fgets(my_num, 30);
        num = atoi(my_num);
    } while (num < ri || num > rf);

    return num;
}
Enfoque educativo: en este ejemplo los prototipos y el desarrollo de las funciones están juntos en el archivo .h. Esto simplifica las prácticas. En proyectos mayores es habitual separar interfaz (.h) e implementación (.c).

11.7 · ¿Cómo se manda llamar desde el programa principal?

Una vez que el archivo está disponible para el proyecto, el programa principal puede incluirlo y utilizar sus funciones.

programa.cpp
#include "kareli_ruiz.h"

int main(void)
{
    char nombre[30];
    int edad;

    printf("DAME UN NOMBRE: ");
    my_fgets(nombre, 30);

    edad = my_int(1, 120, "DAME TU EDAD: ");

    printf("\nNOMBRE: %s\n", nombre);
    printf("EDAD: %d\n", edad);

    return 0;
}
🧠
ABSTRACCIÓN
El main() no necesita conocer todos los pasos usados para validar la edad. Solo sabe que my_int() recibe un rango y un mensaje y devuelve un entero válido.

11.8 · ¿Cuándo crear una librería propia?

1 · Validación recurrente

Si repites el mismo do-while para validar enteros, conviértelo en una función como my_int().

2 · Lectura de cadenas

Si siempre necesitas leer texto y quitar el salto de línea, encapsula esa tarea en my_fgets().

3 · Estandarización

Puedes compartir constantes, tamaños, macros o comportamientos comunes.

4 · Abstracción

El programa principal expresa qué necesita y deja los detalles de cómo hacerlo dentro de la biblioteca.

5 · Mantenimiento

Una corrección o mejora puede concentrarse en un único lugar.

6 · Organización

Separa herramientas generales de la lógica específica de cada práctica.

EN RESUMEN
Una biblioteca permite concentrar soluciones reutilizables. Las librerías estándar proporcionan herramientas generales; las librerías propias reúnen funciones y definiciones creadas por el programador. #include permite incorporar esos recursos al programa y favorece un diseño más limpio, modular y mantenible.
