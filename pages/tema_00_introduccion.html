1 · HISTORIA DE LA PROGRAMACIÓN

La programación ha evolucionado desde instrucciones muy cercanas al hardware hasta lenguajes que permiten expresar soluciones de forma cada vez más clara. En cada etapa se buscó que programar fuera más productivo, menos propenso a errores y más fácil de mantener.

1940–50Lenguaje máquina y código binario.
1950–60Ensamblador y primeros lenguajes de alto nivel.
1960–70Se consolida la programación estructurada.
1972Dennis Ritchie desarrolla C en Bell Labs.
ActualidadConviven múltiples paradigmas y lenguajes.
Idea para recordar: la evolución de los lenguajes no elimina lo anterior; agrega nuevas formas de expresar y organizar soluciones.
2 · DIFERENTES PARADIGMAS DE PROGRAMACIÓN

Un paradigma es una manera general de pensar y organizar la solución de un problema mediante programación.

🧱
Imperativo / ProcedimentalDescribe una secuencia de instrucciones y procedimientos. C es uno de sus lenguajes representativos.
🧩
Orientado a objetosOrganiza el software alrededor de objetos, datos y comportamientos.
🧮
FuncionalDa protagonismo a funciones, expresiones y transformaciones de datos.
📜
DeclarativoSe enfoca en qué resultado se desea, más que en detallar cada paso.
3 · ¿QUÉ ES LA PROGRAMACIÓN ESTRUCTURADA?

Es una forma de construir programas usando bloques claros y un flujo de control comprensible. En lugar de saltos arbitrarios, se busca resolver el problema mediante estructuras bien definidas.

➡️

Secuencia

Las instrucciones se ejecutan una después de otra.

🔀

Selección

El programa elige una ruta según una condición.

🔁

Iteración

Un conjunto de instrucciones se repite mientras sea necesario.

5 · LENGUAJE C · HISTORIA

El lenguaje C fue desarrollado a comienzos de la década de 1970 por Dennis Ritchie en Bell Labs. Su desarrollo estuvo estrechamente relacionado con el sistema operativo UNIX.

C logró combinar acceso de bajo nivel con construcciones de alto nivel, por lo que se volvió muy influyente en sistemas operativos, compiladores, bibliotecas y posteriormente en muchos lenguajes derivados o inspirados en su sintaxis.

C en este curso: nos permite aprender variables, operadores, decisiones, ciclos, funciones, arreglos, estructuras, archivos y modularidad con una sintaxis compacta.

6 · ESTRUCTURA BÁSICA DE UN PROGRAMA EN C
1. Directivas
#include <stdio.h>
2. Función principal
int main(void)
3. Declaraciones
Variables que utilizará el programa.
4. Instrucciones
Entrada, proceso y salida.
5. Retorno
return 0;
Primer programa en C
#include <stdio.h> int main(void) { int edad; printf("Escribe tu edad: "); scanf("%d", &edad); printf("Tu edad es %d años\n", edad); return 0; }
Observa: el programa incluye una biblioteca, entra a main(), declara una variable, recibe un dato con scanf(), muestra información con printf() y termina con return 0;.
7 · LIBRERÍAS Y DIRECTIVA #include

Una biblioteca reúne declaraciones y herramientas ya preparadas para utilizarse. La directiva #include hace disponible el contenido de un archivo de cabecera antes de compilar el programa.

<stdio.h>

Entrada y salida estándar. Aquí se encuentran las declaraciones de funciones como printf() y scanf().

#include <stdio.h>

Otras cabeceras comunes

#include <stdlib.h> #include <math.h> #include <string.h>

Se incorporan conforme el programa necesita herramientas adicionales.

👆 Haz clic: ¿#include copia una biblioteca completa dentro de mi programa?
No necesariamente. Conceptualmente, el preprocesador incorpora el contenido del archivo de cabecera indicado. Ese archivo contiene principalmente declaraciones, definiciones y macros necesarias para compilar correctamente el código que usa esas funciones.
8 · SECUENCIAS DE ESCAPE

Las secuencias de escape permiten representar caracteres especiales dentro de cadenas de texto. Comienzan con una diagonal invertida \.

\nNueva línea
\tTabulación
\"Comillas dobles
\\Diagonal invertida
Ejemplo
printf("Nombre:\tAna\nEdad:\t20\n"); printf("Ella dijo: \"Hola\"\n"); printf("Ruta: C:\\Programas\\C\n");
9 · COMENTARIOS EN C

Los comentarios ayudan a documentar el programa. El compilador los ignora, pero son muy útiles para explicar decisiones, secciones y propósito del código.

Comentario de una línea

// Calcula el promedio promedio = suma / 3.0;

Comentario de varias líneas

/* Programa de ejemplo Tema 0 */
Buena práctica: comenta el porqué cuando sea necesario. Evita comentarios que simplemente repitan lo evidente del código.
10 · SENTENCIA DE ENTRADA · scanf()

scanf() permite leer datos desde la entrada estándar. Para variables numéricas normalmente se utiliza el operador & para proporcionar su dirección de memoria.

Ejemplo con entero
int edad; printf("Edad: "); scanf("%d", &edad);
FormatoDato típico
%dint
%ffloat
%lfdouble
%cchar
%scadena sin espacios
11 · SENTENCIA DE SALIDA · printf()

printf() envía texto y valores a la salida estándar. Puede combinar texto fijo con especificadores de formato.

Ejemplo
int edad = 20; float promedio = 9.5; printf("Edad: %d\n", edad); printf("Promedio: %.1f\n", promedio);

12 · PROGRAMA INTEGRADOR DEL TEMA 0

Este ejemplo reúne biblioteca, main(), comentarios, variables, scanf(), printf() y secuencias de escape.

Programa completo
#include <stdio.h> int main(void) { /* Variables de entrada */ int edad; float estatura; printf("=== DATOS DEL ESTUDIANTE ===\n"); printf("Edad: "); scanf("%d", &edad); printf("Estatura en metros: "); scanf("%f", &estatura); printf("\n--- RESULTADO ---\n"); printf("Edad:\t%d años\n", edad); printf("Estatura:\t%.2f m\n", estatura); return 0; }
