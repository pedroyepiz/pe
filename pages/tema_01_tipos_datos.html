🧠 ¿Qué es un tipo de dato?

La memoria de la computadora solo almacena bits. Un tipo de dato le dice al compilador cuánta memoria reservar, cómo interpretar esos bits y qué operaciones son válidas.

📦

Reserva memoria

Determina cuánto espacio necesita una variable.

🔍

Interpreta bits

Los mismos bits pueden significar números, caracteres u otros valores.

⚙️

Define operaciones

Controla qué cálculos y conversiones son válidos.

💾 1 byte = 8 bits

1.2 · TAMAÑO DE LOS TIPOS DE DATOS

El tamaño exacto depende del compilador y de la arquitectura. Por eso, en C conviene preguntar al sistema en lugar de asumir.

sizeof.c
printf("Tamaño de int: %zu bytes\n", sizeof(int));
printf("Tamaño de double: %zu bytes\n", sizeof(double));

int x = 100;
printf("Tamaño de x: %zu bytes\n", sizeof(x));
✅ Usa %zu para imprimir el resultado de sizeof, porque devuelve un valor de tipo size_t.

1.3 · ESPECIFICADORES DE FORMATO

printf() y scanf() necesitan saber qué tipo de dato están manejando. El especificador debe coincidir con el tipo.

%dintentero decimal
%ccharcarácter
%ffloat/doublesalida con printf
%lfdoubleentrada con scanf
%schar[]cadena
%uunsigned intentero sin signo
%xenterohexadecimal
%ppunterodirección
🚨 Con cadenas, evita scanf("%s", nombre) sin límite. Para un arreglo de 100 caracteres, usa scanf("%99s", nombre).
formatos.c
double precio = 19.99;

printf("Precio: %8.2f\n", precio); //    19.99
printf("ID: %06d\n", 42);          // 000042
✅ Regla de oro: el especificador debe coincidir exactamente con el tipo del argumento. Con GCC, compila con gcc -Wall -Wextra programa.c -o programa.
1.4 · MODIFICADORES Y CALIFICADORES
➕

signed

Permite valores negativos y positivos.

🔢

unsigned

Solo cero y positivos; amplía el rango positivo.

🔒

const

El valor no debe modificarse después de inicializarse.

⚡

volatile

El valor puede cambiar por hardware u otros mecanismos externos.

modificadores.c
unsigned int contador = 0;
signed char c = -50;

const double PI = 3.14159;
// PI = 3.14;  // error de compilación

volatile int *sensor = (int*)0x4000;
1.5 · TIPOS COMPUESTOS

C también permite construir tipos más complejos. En este tema solo los presentamos; más adelante se estudian con detalle.

📦

struct

Agrupa datos relacionados de distintos tipos bajo un solo nombre.

🏷️

typedef

Crea alias de tipos para mejorar legibilidad y mantenimiento.

📊

Arreglos de estructuras

Permiten almacenar colecciones de registros del mismo tipo.

struct_estudiante.c
typedef struct {
    char nombre[50];
    int edad;
    float promedio;
} Estudiante;

Estudiante alumno = {"Ana", 21, 9.3f};
printf("%s tiene %d años y promedio %.1f\n",
       alumno.nombre, alumno.edad, alumno.promedio);
