1.1. Introducción a la metodología para la solución de problemas

Una metodología es una secuencia ordenada de pasos que permite transformar una situación problemática en una solución verificable. En programación, ayuda a separar el qué se necesita resolver del cómo se implementará.

1. Comprender

Identificar la situación, alcance, restricciones y resultado esperado.

2. Diseñar

Proponer un algoritmo y representarlo antes de escribir código.

3. Verificar

Probar la lógica con datos y corregir inconsistencias.

1.2. Problema

1.2.1. Definición del problema

Definir un problema consiste en expresar con claridad qué situación debe resolverse y cuál es el resultado esperado, evitando ambigüedades.

1.2.2. Análisis del problema

El análisis identifica entradas, proceso y salidas, además de condiciones o restricciones.

Ejemplo: promedio de tres calificaciones.
Entradas: c1, c2, c3. Proceso: (c1+c2+c3)/3. Salida: promedio.

1.3. Algoritmo

1.3.1. Definición de algoritmo

Un algoritmo es una secuencia ordenada y finita de pasos para resolver un problema.

1.3.2. Características de un algoritmo

  • Debe ser preciso y no ambiguo.
  • Debe tener un inicio y un fin.
  • Sus pasos deben ejecutarse en un orden definido.
  • Debe producir un resultado para las entradas válidas.
  • Debe poder verificarse mediante pruebas.

1.3.3. Prueba de escritorio

La prueba de escritorio simula manualmente la ejecución del algoritmo. Se asignan valores de entrada y se sigue cada paso para comprobar resultados.

1.4. Diagrama de Flujo

1.4.1. Definición de diagrama de flujo

Es la representación gráfica de un algoritmo mediante símbolos conectados por flechas que muestran la secuencia de ejecución.

1.4.2. Reglas para la construcción de un diagrama de flujo

  • Usar un inicio y un fin claramente identificados.
  • Mantener el flujo de arriba hacia abajo o de izquierda a derecha.
  • Conectar los símbolos con líneas o flechas.
  • Evitar líneas cruzadas cuando sea posible.
  • Expresar una acción clara dentro de cada símbolo.

1.4.3. Simbología

Óvalo

Inicio o fin.

Rectángulo

Proceso o cálculo.

Rombo

Decisión o condición.

Paralelogramo

Entrada o salida.

Flecha

Dirección del flujo.

Conector

Continuidad del diagrama.

1.5. Pseudocódigo

El pseudocódigo describe el algoritmo con instrucciones cercanas al lenguaje humano, sin depender todavía de la sintaxis de un lenguaje de programación.

PSeInt · Promedio de tres calificaciones
Proceso PromedioTresCalificaciones
  Definir c1, c2, c3, promedio Como Real
  Leer c1, c2, c3
  promedio <- (c1 + c2 + c3) / 3
  Escribir "Promedio: ", promedio
FinProceso

1.6. Codificación

1.6.1. Definición de codificación

La codificación es la traducción del algoritmo a un lenguaje o entorno concreto, respetando su sintaxis. En esta materia, PSeInt se utiliza para practicar la lógica antes de trasladarla a otros lenguajes.

Idea clave: si el análisis y el algoritmo están bien construidos, la codificación deja de ser el punto de partida y se convierte en la implementación de una solución ya pensada.

1.7. Depuración

1.7.1. Definición de depuración

La depuración es el proceso de localizar y corregir errores detectados durante la ejecución o las pruebas. Puede incluir errores de lógica, de datos o de sintaxis.

Práctica sugerida. Plantea un problema para calcular el área de un rectángulo. Escribe: definición, entradas, proceso, salida, algoritmo, prueba de escritorio, diagrama de flujo y pseudocódigo.
