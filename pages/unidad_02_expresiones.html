Resolver problemas de ingeniería, a través de la aplicación de los diferentes tipos de operadores, para la construcción de expresiones aritméticas, relacionales y lógicas, con una actitud responsable y propositiva.

Una expresión combina datos y operadores para producir un valor. Antes de construir condiciones o ciclos, es necesario dominar cómo se representan los datos y en qué orden se evalúan las operaciones.

2.1. Variables y Constantes

Variable

Espacio lógico cuyo valor puede cambiar durante la ejecución.

Constante

Valor que permanece sin cambios durante la solución del problema.

Identificador

Nombre utilizado para referirse a una variable o constante.

2.3.4. Operadores de agrupación

Los paréntesis permiten indicar qué parte de una expresión debe evaluarse primero y hacen explícita la intención del algoritmo.

2.3.5. Jerarquía de operadores

  1. Paréntesis.
  2. Potencias.
  3. Multiplicación, división y módulo.
  4. Suma y resta.
  5. Relacionales.
  6. Lógicos: NO, Y, O.
Ejemplo. En 2 + 2 / 4 * 2 + 1, primero se evalúan división y multiplicación; después suma y resta de izquierda a derecha.

2.4. Expresiones

2.4.1. Expresiones aritméticas

Combinan operandos numéricos y operadores aritméticos para obtener un valor numérico.

PSeInt · Expresión aritmética
area <- base * altura
promedio <- (c1 + c2 + c3) / 3

2.4.2. Expresiones relacionales

Comparan valores y producen un resultado lógico.

PSeInt · Expresión relacional
edad >= 18
promedio >= 60

2.4.3. Expresiones lógicas

Combinan una o más condiciones mediante operadores lógicos.

PSeInt · Expresión lógica
(edad >= 18) Y (tieneIdentificacion = Verdadero)
(promedio >= 60) O (extraordinario = Verdadero)
