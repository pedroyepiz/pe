6.0 · ¿QUÉ ES UN ARREGLO?
📦

Múltiples datos bajo un mismo nombre

Un arreglo permite almacenar múltiples valores del mismo tipo en una sola variable y acceder a ellos usando un índice numérico.

En C, sus elementos ocupan posiciones contiguas en memoria.

Tres usos principales

✅ Arreglos unidimensionales → listas o vectores.

✅ Cadenas de caracteres → arreglos de char terminados en \0.

✅ Arreglos multidimensionales → matrices, tablas o grillas.

6.1 · ARREGLOS UNIDIMENSIONALES

Un arreglo unidimensional es una secuencia de elementos del mismo tipo, almacenados en posiciones contiguas.

[0]10
[1]20
[2]30
[3]40
[4]50
arreglo_basico.c 
#include <stdio.h>

int main() {
    int numeros[5] = {
        10, 20, 30, 40, 50
    };

    printf("%d\n", numeros[0]);

    numeros[2] = 99;

    return 0;
}
⚠️ Los índices válidos van de 0 a tamaño - 1. Acceder fuera del arreglo produce comportamiento indefinido.
6.1.2 · RECORRIDO CON CICLOS

Los ciclos for son especialmente adecuados para recorrer arreglos.

suma_arreglo.c 
int valores[] = {
    4, 8, 15, 16, 23, 42
};

int n = sizeof(valores) / sizeof(valores[0]);
int suma = 0;

for (int i = 0; i < n; i++) {
    suma += valores[i];
}

printf("Suma total: %d\n", suma);
sizeof(arreglo) / sizeof(arreglo[0]) permite calcular el número de elementos mientras el arreglo siga siendo un arreglo real en ese mismo ámbito.
6.1.3 · ARREGLOS COMO PARÁMETROS DE FUNCIONES

Cuando un arreglo se envía a una función, se utiliza la dirección del primer elemento. Por eso, normalmente hay que enviar también su tamaño.

arreglo_funcion.c 
void imprimir_arreglo(int arr[],
                       int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
}

int datos[] = {1, 1, 2, 3, 5, 8};
imprimir_arreglo(datos, 6);
Dentro de la función, sizeof(arr) ya no permite conocer la cantidad original de elementos, porque el parámetro se trata como un puntero.
6.2 · CADENAS DE CARACTERES — PUNTO CLAVE DEL TEMA
En C no existe un tipo de dato “string” nativo. Una cadena es un arreglo de char que termina con el carácter nulo '\0'.
🔤

Representación

char texto[] = "Hola";

El compilador agrega automáticamente el terminador \0.

🛡️

La seguridad depende del tamaño

Una cadena correcta necesita espacio para todos sus caracteres más un byte adicional para \0.

[0]'H'
[1]'o'
[2]'l'
[3]'a'
[4]'\0'
cadena_basica.c 
char cadena[5] = "Hola";

// Equivalente:
char otra[] = {
    'H', 'o', 'l', 'a', '\0'
};

printf("%s\n", cadena);
Si una secuencia de caracteres no contiene \0, funciones como printf("%s") pueden seguir leyendo memoria fuera del arreglo.
6.2.3 · LIBRERÍA <string.h>

🧰 Biblioteca fundamental para trabajar con cadenas

Para utilizar las funciones estándar de manejo de cadenas se debe incluir: #include <string.h>

Función Para qué sirve Ejemplo
strlen(s) Obtiene la longitud de la cadena sin contar \0. strlen("Hola") → 4
strcpy(dest, src) Copia una cadena en otra. strcpy(destino, "Hola");
strcat(dest, src) Concatena una cadena al final de otra. strcat(mensaje, nombre);
strcmp(a, b) Compara dos cadenas; devuelve 0 si son iguales. strcmp(a,b) == 0
strcspn(s, "\n") Localiza el primer salto de línea; útil para limpiarlo después de fgets. nombre[strcspn(nombre,"\n")] = '\0';
string_h.c 
#include <stdio.h>
#include <string.h>

int main() {
    char nombre[50] = "Ana";
    char saludo[100] = "Hola, ";

    strcat(saludo, nombre);

    printf("%s\n", saludo);

    if (strcmp(nombre, "Ana") == 0) {
        printf("¡Bienvenida!\n");
    }

    printf("Longitud: %zu\n", strlen(saludo));

    return 0;
}
strcpy y strcat no comprueban automáticamente si el destino tiene espacio suficiente. Antes de copiar o concatenar, hay que asegurarse de que el arreglo destino sea suficientemente grande.
6.2.4 · CÓMO LEER CADENAS CORRECTAMENTE

scanf("%s")

Lee una palabra y se detiene en el primer espacio.

Debe usarse con límite de ancho para reducir riesgos.

fgets()

Lee una línea completa, incluyendo espacios.

Limita la cantidad máxima de caracteres.

puts() y printf("%s")

Permiten mostrar cadenas; puts() agrega salto de línea automáticamente.

fgets_seguro.c 
#include <stdio.h>
#include <string.h>

int main() {
    char nombre[30];

    printf("Ingresa tu nombre: ");

    fgets(nombre, sizeof(nombre), stdin);

    nombre[strcspn(nombre, "\n")] = '\0';

    printf("Hola, %s.\n", nombre);

    return 0;
}
Ventaja de fgets: escribe como máximo tamaño - 1 caracteres y deja espacio para el terminador \0.
Si utilizas scanf antes de fgets, puede quedar un salto de línea pendiente en la entrada. Es importante planear correctamente la lectura del búfer.
6.2.5 · COMPARAR CADENAS: NO USAR ==
En C, cadena1 == cadena2 no compara el contenido de las cadenas. Para comparar texto se usa strcmp().
comparar_cadenas.c 
char usuario[20] = "Pedro";

if (strcmp(usuario, "Pedro") == 0) {
    printf("Las cadenas son iguales.\n");
}
6.3 · ARREGLOS MULTIDIMENSIONALES

Un arreglo bidimensional representa una tabla o matriz mediante filas y columnas.

Declaración

int matriz[3][3];

2
4
6
1
3
5
7
8
9
matriz.c 
int mat[3][3] = {
    {2, 4, 6},
    {1, 3, 5},
    {7, 8, 9}
};

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", mat[i][j]);
    }
    printf("\n");
}
6.3.3 · ARREGLOS DE CADENAS

Un arreglo bidimensional de char puede almacenar varias cadenas, donde cada fila representa una cadena independiente.

arreglo_cadenas.c 
char dias[3][10] = {
    "Lunes",
    "Martes",
    "Miércoles"
};

for (int i = 0; i < 3; i++) {
    printf("Día %d: %s\n", i + 1, dias[i]);
}
Cada fila debe tener suficiente espacio para contener la cadena más larga y su \0.
