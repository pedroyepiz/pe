Archivos de texto usando estructuras

Ejemplo de creación y lectura de un archivo de texto a partir de un vector de registros de tipo Ts_alum.

“Del vector en memoria al archivo: guardar, cerrar y recuperar información.”

📂 Propósito del ejemplo

Este programa trabaja con un vector de registros Ts_alum y muestra cómo convertir esos registros en líneas de un archivo de texto. La función crea_arch() abre el archivo con modo "w", recorre el vector y escribe cada registro activo con fprintf().

Posteriormente, lee_arch() abre el archivo con modo "r" y lo muestra carácter por carácter utilizando fgetc().

💡
IDEA CLAVE
El vector mantiene los registros en memoria. El archivo de texto permite conservar una representación legible de esos datos después de terminar el programa.

Flujo del ejemplo

🧑‍🎓

1. Registros

El programa trabaja con un vector Ts_alum vec_reg[1000].

📝

2. Crear archivo

crea_arch() abre con "w" y escribe con fprintf().

💾

3. Persistencia

Los datos activos quedan almacenados en un archivo de texto.

📖

4. Leer archivo

lee_arch() abre con "r" y lee usando fgetc().

Abre el archivo indicado por el usuario, imprime un encabezado y recorre el vector. Solo escribe los registros cuyo campo status vale 1. El registro se convierte a una línea de texto mediante fprintf().

void  lee_arch(const char nombre[])
{
   char caracter;
   FILE *arch;
   arch = fopen(nombre,"r");
   if (arch)
   {
     
     while ( ! feof(arch) )
     {
        caracter=fgetc(arch);
        fprintf (stdout,"%c",caracter);
     }
     system ("PAUSE");
     
     
     fclose(arch);
   }
   else
   {
    printf (" NO SE PUDO ABRIR EL ARCHIVO \n");
    system ("PAUSE");
   } 
}

void my_fgets(char string[],int tam)
{

  fflush(stdin);
  fgets(string,tam,stdin);
  while (string[i] != '\0')
  {
    i++;
  }
  string[i-1]='\0';
}
