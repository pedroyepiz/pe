5.0 · ABSTRACCIÓN PROCEDIMENTAL
🧩

¿Qué significa abstraer?

La abstracción procedimental consiste en ocultar los detalles de implementación y exponer solo qué hace una parte del programa.

Una función actúa como una pequeña “caja negra”: quien la usa necesita conocer su propósito, sus entradas y su salida, no cada instrucción interna.
🧠

Resolver problemas complejos

Problema grande→ Subproblemas→ Funciones→ Programa

La idea central es dividir y vencer: transformar una tarea difícil en varias tareas pequeñas y comprensibles.

5.1 · DISEÑO DESCENDENTE

El diseño descendente parte del todo y lo divide progresivamente en partes más pequeñas, hasta llegar a operaciones simples que pueden implementarse como funciones.

🗺️

1 · Analizar

Identificar qué debe resolver el programa.

🧱

2 · Dividir

Separar el problema en tareas y subtareas.

⚙️

3 · Implementar

Convertir cada tarea en una función clara.

jerarquia_funciones.c 
int main() {
    preparar_cafe();
    return 0;
}

void preparar_cafe() {
    hervir_agua();
    moler_cafe();
    servir();
}
5.2 · FUNCIONES: QUÉ SON Y PARA QUÉ SIRVEN
♻️

Reutilizar

Escribir una vez y utilizar la misma lógica en varios lugares.

🧩

Modularizar

Dividir programas grandes en bloques pequeños.

🔍

Depurar

Aislar errores y probar una parte del programa de forma independiente.

🛠️

Mantener

Modificar solo el módulo necesario sin rehacer todo el programa.

5.2.1 · PROTOTIPO, DESARROLLO Y LLAMADA

Prototipo

Declara el tipo de retorno, nombre y parámetros antes de utilizar la función.

int sumar(int, int);

Desarrollo

Es la definición completa de la función: encabezado + cuerpo.

int sumar(int a, int b) { ... }

Llamada

Ejecuta la función usando su nombre y, si corresponde, enviando argumentos.

total = sumar(3, 5);
funcion_basica.c 
#include <stdio.h>

// Prototipo
int suma(int, int);

int main() {
    int resultado = suma(5, 3);
    printf("5 + 3 = %d\n", resultado);
    return 0;
}

// Desarrollo
int suma(int a, int b) {
    return a + b;
}
5.2.2 · FUNCIONES void
🚫

Ejecutan acciones sin regresar valor

Una función void realiza una tarea concreta, pero no entrega un resultado mediante return valor;.

Puede mostrar información, imprimir reportes, desplegar menús, pedir datos o controlar pasos del programa.
funcion_void.c 
void saludar(void) {
    printf("Hola\n");
}

int main() {
    saludar();
    return 0;
}
Una función void puede usar return; para salir anticipadamente, pero sin devolver un valor.
5.4 · FUNCIONES CON RETORNO
↩️

Procesan y devuelven un resultado

Las funciones con retorno son adecuadas cuando el programa necesita un valor para utilizarlo después en una asignación, expresión, comparación o cálculo.

Entrada→ Proceso→ Resultado
retorno.c 
double promedio(double a,
                     double b) {
    return (a + b) / 2.0;
}
El valor devuelto debe ser compatible con el tipo declarado en la función.
5.3 · PARÁMETROS Y ARGUMENTOS
Concepto Dónde aparece Ejemplo
Parámetros En el prototipo o definición de la función. int sumar(int a, int b)
Argumentos En la llamada a la función. sumar(3, 5)
En C, los argumentos se pasan por valor: la función recibe una copia. Modificar el parámetro no modifica automáticamente la variable original.
paso_por_valor.c 
void intentar_cambiar(int x) {
    x = 99;
}

int main() {
    int num = 10;
    intentar_cambiar(num);
    printf("%d\n", num); // sigue siendo 10
    return 0;
}
5.5 · FUNCIONES REUTILIZABLES VS FUNCIONES DESECHABLES
Reutilizable Desechable / muy específica
Propósito general y claro. Ligada a una pantalla, menú o impresión particular.
Recibe parámetros útiles. Depende de datos o variables muy específicas.
Puede devolver valores aprovechables. Frecuentemente solo ejecuta una acción local.
Bajo acoplamiento con el contexto. Fuerte dependencia del contexto del programa.
Útil desde distintos lugares. Difícil de adaptar o reutilizar.

Señales de reutilización

Una sola responsabilidad, parámetros útiles, nombres descriptivos, pocas dependencias y salida clara.

Cuándo no forzarla

Si la tarea es extremadamente local y específica, una función puntual puede ser perfectamente válida.

Regla práctica

Primero piensa en reutilizar; si no aporta valor real, simplifica.

5.6 · INTRODUCCIÓN A PUNTEROS Y FUNCIONES

Un puntero es una variable que almacena la dirección de memoria de otra variable. En funciones permite simular un paso “por referencia” para modificar datos originales.

variable valor
contenido: 42
←
puntero p
guarda &valor
puntero_basico.c 
int valor = 42;
int *p = &valor;

printf("%d\n", *p); // 42

*p = 100;
printf("%d\n", valor); // 100
5.6.1 · MODIFICAR DOS VARIABLES CON PUNTEROS
intercambiar.c 
void intercambiar(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int x = 5, y = 10;
intercambiar(&x, &y);
Claves: la función recibe punteros, la llamada envía direcciones y el operador * permite acceder o modificar el valor original.
5.7 · DEVOLVER MÚLTIPLES RESULTADOS
📦

Usar una estructura

Conveniente cuando los resultados están lógicamente relacionados, por ejemplo mínimo/máximo.

📍

Usar punteros

Conveniente cuando ya existen variables y quieres actualizarlas desde la función.

multiples_resultados.c 
void dividir(int a, int b,
             int *cociente, int *resto) {
    *cociente = a / b;
    *resto = a % b;
}

int c, r;
dividir(17, 5, &c, &r);

1. ¿Qué es un parámetro?
2. ¿Qué tipo de función no devuelve un valor?
3. En C, ¿cómo se pasan normalmente los argumentos?

En resumen: las funciones permiten modularizar, reutilizar y mantener mejor el código. Los parámetros transportan datos hacia una función; return permite devolver resultados; void representa funciones sin valor de retorno; y los punteros permiten modificar variables originales y trabajar con múltiples resultados.
