Alias y abstracción de tipos

Un alias para un tipo de dato existente: claridad, mantenimiento, estandarización y mejor lectura del código.

“Cambiar el nombre no cambia el tipo, pero sí puede cambiar la claridad del programa.”
IDEA CENTRAL

typedef crea un alias, no un tipo nuevo

La palabra clave typedef permite crear un sinónimo para un tipo de dato existente. El compilador trata al alias y al tipo original como equivalentes.

8.1 · ¿Qué es typedef?

typedef significa Type Definition y permite asignar un nuevo nombre a un tipo que ya existe.

alias_basico.c
typedef unsigned short int Tentero;

Tentero edad;
Tentero cantidad;
👤
Analogía del apodo: “José Antonio Pérez García” puede ser llamado “Chepe”. Sigue siendo la misma persona. De la misma forma, Tentero sigue representando el tipo original; solo cambia el nombre con el que lo usamos en el programa.
⚠️
NO CONFUNDIR
typedef no crea automáticamente un tipo con comportamiento nuevo. Crea un nombre alternativo para un tipo ya existente.

8.2 · ¿Para qué sirve?

📖

Legibilidad

Tkey matricula; comunica mejor la intención que int matricula;.

🧰

Mantenimiento

Si el tipo base cambia, puede modificarse en un solo typedef en lugar de cambiar muchas declaraciones.

🧩

Simplificación

Reduce la complejidad visual de tipos compuestos, estructuras y otras declaraciones largas.

🧭

Estandarización

Una convención de nombres permite reconocer rápidamente qué tipos fueron definidos por el programador.

mantenimiento.c
/* Hoy */
typedef int Tkey;

Tkey matricula;
Tkey id_alumno;

/* Si después se requiere un rango mayor: */
typedef long long Tkey;

/* Las variables siguen usando Tkey */

8.3 · Sintaxis básica

typedef <tipo_existente> <nuevo_nombre_alias>;
Tipos simples
typedef int Tentero;
typedef int Tkey;
typedef float Tpromedio;
typedef char Tcaracter;

Tentero contador;
Tkey matricula;
Tpromedio calificacion;
Semántica
typedef int Tkey;

Tkey matricula = 12345;
Tkey id_usuario = 9001;

/* Ambos siguen siendo int,
   pero el alias comunica que
   representan llaves o IDs. */

Convención de nomenclatura de clase

El manual propone un sistema visual para distinguir tipos simples aliasados y tipos compuestos definidos por el programador.

Tipo Prefijo Ejemplo Lectura visual
Tipos simples T Tentero, Tkey, Tflag Tipo básico aliasado por nosotros.
Tipos compuestos / estructuras sT sTalum, sTnom, sTproducto Estructura definida por nosotros.
🎓
REGLA DE LA CLASE
La convención no es una obligación del lenguaje C; es una disciplina de nomenclatura que ayuda a leer y mantener los programas del curso.

typedef aplicado a struct

Una de las aplicaciones más útiles de typedef es simplificar la declaración de estructuras.

alumno.c
typedef int Tkey;

typedef struct _nom
{
    char nombre[30];
    char appat[30];
    char apmat[30];
} sTnom;

typedef struct _talum
{
    int status;
    Tkey matri;
    sTnom nombre;
    int edad;
    int sexo;
} sTalum;

int main(void)
{
    sTalum alumno1;

    alumno1.matri = 2026001;
    alumno1.edad = 20;

    return 0;
}
Lectura semántica: cuando ves Tkey matri;, sabes que matri representa una llave. Cuando ves sTnom nombre;, sabes que nombre es una estructura definida por el programador.

8.4 · Buenas prácticas y archivos de cabecera

El manual recomienda centralizar los typedef en un archivo de cabecera, por ejemplo tipos.h o definiciones.h, para reutilizarlos en diferentes programas.

tipos.h
#ifndef TIPOS_H
#define TIPOS_H

typedef int Tentero;
typedef int Tkey;

typedef struct _nom
{
    char nombre[30];
    char appat[30];
    char apmat[30];
} sTnom;

#endif
🧱

Centralizar

Evita tener definiciones dispersas en muchos archivos fuente.

🛡️

Guardas de inclusión

#ifndef, #define y #endif evitan inclusiones repetidas del mismo archivo.

Conexión con sistemas embebidos y tipos de ancho fijo

El manual relaciona typedef con la idea de abstracción que se utiliza en sistemas embebidos. En C moderno, la cabecera <stdint.h> ofrece tipos como uint8_t, int16_t y uint32_t, cuyo ancho está especificado cuando la implementación los proporciona.

uint8_tEntero sin signo de 8 bits
int16_tEntero con signo de 16 bits
uint32_tEntero sin signo de 32 bits
stdint.c
#include <stdint.h>

uint8_t nivel = 255;
int16_t temperatura = -120;
uint32_t contador = 1000000;
Precisión importante: el tamaño de tipos como int depende de la implementación. Por eso, cuando el ancho exacto es importante, los tipos de <stdint.h> pueden ser más adecuados.

💡 Ejercicio rápido

Si encuentras esta declaración:

sTnom datos_contacto;

¿Qué puedes deducir solo leyendo el nombre del tipo?

  • La s indica que trabajamos con una estructura según la convención de clase.
  • La T indica que es un tipo definido por nosotros.
  • nom sugiere que representa datos relacionados con un nombre.

Buenas prácticas

1. Usa alias que comuniquen intención, no nombres ambiguos.
2. Mantén una convención de nombres consistente en todo el proyecto.
3. Centraliza los tipos compartidos en archivos .h.
4. No abuses de typedef si el alias no mejora la lectura.
5. Documenta el propósito de los alias importantes.
6. Usa tipos de ancho fijo cuando el tamaño exacto del dato sea relevante.

EN RESUMEN
typedef permite crear nombres alternativos para tipos existentes. Bien utilizado mejora la legibilidad, la organización y el mantenimiento. En nuestra convención de clase, T... identifica tipos simples aliasados y sT... identifica estructuras definidas por nosotros.
